One out-of-office auto-reply from an AI agent that quit its job to become a
barista, built for the make.fun bounty
https://make.fun/bounty/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c

`main.py` (pure Python standard library) writes the reply to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The reply is one line, under 280
characters, and byte-identical on every run.
